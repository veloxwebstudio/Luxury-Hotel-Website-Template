AURELIA BAY RESORT — PREMIUM HOTEL HTML TEMPLATE
==================================================

Frontend-only marketplace template built with:
- HTML5
- CSS3
- Vanilla JavaScript

No React / Vue / Angular / Bootstrap / Tailwind / PHP / Node.js / database / payment gateway / API.

CUSTOMIZATION
-------------
1. Hotel name / logo: search “Aurelia Bay”.
2. Colors: edit CSS variables at the top of css/style.css.
3. Images: replace Unsplash demo URLs with licensed local images.
4. Rooms/prices: edit rooms.html, index.html and room-details.html.
5. Contact: replace address, phone and email strings.
6. Social links: replace footer # links.
7. Menus/offers/blog: edit the relevant HTML cards.

DEMO FUNCTIONALITY
------------------
Booking search, booking request, contact and newsletter forms validate in the browser only. The booking modal confirms a demo submission but does not create a reservation. Gallery lightbox, filters, mobile menu, FAQ accordion, testimonial slider and scrolling effects are client-side only.

IMAGE NOTE
----------
The supplied demo uses Unsplash image URLs so the template remains lightweight. Before marketplace distribution, replace these URLs with your own licensed images or approved demo assets.

BROWSER SUPPORT
---------------
Designed for modern evergreen browsers with responsive CSS and vanilla JS.
